# ミッション定義 (Mission)

## プロジェクト名: fujitashu（藤田周の個人サイト）

### ビジョン
日記・プロフィール・喚起的編集の活動を、一つの落ち着いたサイトに置き、検索や研究者情報から辿り着ける場所にする。

### ミッション
汎用テンプレート (`my-simple-diary`) から派生した、藤田周の個人サイト。日記は GitHub の Web 画面から書き、AI エージェントはページの改修と保守を受け持つ。2026-04 の開設時は匿名の日記だったが、2026-10-15 に実名のサイト名にし、2026-11-07 に実名公開を前提とすると藤田が確認した。

### 成功基準 (Definition of Done)
1. **読みやすさ**: 日記と固定ページが、PC でもスマホ幅でも読みやすいこと。
2. **執筆の容易さ**: GitHub の Web 画面から、ストレスなく日記を足せること。足すと Bluesky にも通知が出ること。
3. **見つけられること**: 「藤田周」「Shu Fujita」で検索したときに、このサイトがトップページから出てくること。researchmap などの外部プロフィールと相互にリンクされていること。

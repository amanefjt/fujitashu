# コンテンツフォーマット規約 (Content Format)

## 日記記事の管理ルール

### 1. ファイル名
- **場所**: `content/diary/`
- **形式**: `YYYY-MM-DD.md` (例: `2026-04-01.md`)
- **理由**: 名前順で並べた際に日付順になるようにするため。

### 2. フロントマター (Front Matter)
記事の冒頭には、以下の形式でメタデータを記述する必要があります。既存の日記 159 本はすべてこの形式です。

```yaml
---
title: "2026年4月1日（水）タイトル"
date: 2026-04-01
slug: "2026-04-01"
draft: false
---
```

- `title`: 「YYYY年M月D日（曜）タイトル」。タイトルは日付のあとに続ける。
- `date`: 公開日。Hugo が並び替えに使用する。
- `slug`: URL になる（`/diary/2026-04-01/`）。ファイル名と同じにする。**これを変えると URL が変わり、Bluesky の投稿や外部からのリンクが切れる**。
- `draft`: `false` で本番公開。

### 3. 本文の構成
- **内容**: Markdown 形式で自由に記述。
- **生HTML**: `hugo.toml` の `unsafe = true` 設定により、既存の HTML タグもそのまま使用可能。

### 4. 固定ページ（プロフィール・喚起的編集）
- `type: page` を指定し、検索結果に出る説明文を `description:` に書く（なければサイト共通の説明文になる）。
